# Search Recovery · E03

| Наблюдение | Следующий шаг | Доказательство для закрытия |
|---|---|---|
| Ошибка lookup по заводскому артикулу | Бренд + артикул в текстовом поиске | Карточка и обязательные поля, отдельный код ВИ |
| Релевантная категория с неподходящими первыми товарами | Запрос по модели, затем поиск по домену ВИ | GROSS 15605 и AEG 4935464417 найдены таким веб-добором в предыдущих срезах |
| Несколько карточек на один артикул | Сверка состава, сохранение всех ID | Сценарий HOEGERT HT1W804 |
| Отличается серия или единица измерения | Сверка с документацией изготовителя и исходным ТЗ | CUTOP и GROSS остаются спорными до подтверждения |

В журнале хранить канал первого обнаружения и канал подтверждения отдельно. Кандидаты из старых срезов не включаются в метрики нового запуска. Ожидаемый эффект — восстановление пропущенных карточек. Риск — принятие карточки с похожим названием. Приёмка — подтверждение всех обязательных условий и сохранение причины отказа.
