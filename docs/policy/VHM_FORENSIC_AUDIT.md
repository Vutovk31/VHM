# Аудит VHM Core · Phase 0

База `ccb11de35880115b8f0374395b259ce02ce804bb`. В дереве уже есть JavaScript Matcher, экспорт четырёх листов, скрипт сравнения и проектный навык. Приём, извлечение требований, запросы к источникам и формирование доказательств в пилоте организует Codex. Внешний процесс со своим MCP-клиентом и проверенным входом в приложение отсутствует в проверенном дереве.

| Источник | Конфликт или граница | Решение |
|---|---|---|

| E03.5 ABC и локальные журналы | C имеет больше принятых карточек на ручной разметке, независимый эталон покрывает лишь часть выборки | UNDECIDED. E03.6 обязателен до rollout |
| E04 Design и старая схема E03 | Схема E03 фиксирует один протокол. Runtime 1.1.0 жёстко задаёт свои поля | Новый управляемый конфиг в режиме dry-run. Ядро остаётся неизменным |
