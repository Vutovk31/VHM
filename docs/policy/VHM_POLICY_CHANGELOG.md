# История проекта политики

## 0.1.0 · черновик

- Вынесены настройки A/B/C, глубина, бюджеты и recovery.
- Закреплены обязательная проверка SKU, граница согласования аналогов и область действия коммерческих предпочтений.
- Добавлены схема, проверка конфигурации, dry-run без сетевых вызовов, сравнение версий и расчёт плана отката.
- Маршрут для runtime остаётся UNDECIDED. Расширенный Golden Set, сравнительный replay и утверждение владельца требуются для включения.
