# VHM · реестр рисков

| ID | Риск и последствие | Контроль | Ответственная роль | Статус |
|---|---|---|---|---|
| R-01 | Конфликт регламентов или версий A/B/C даёт несовместимые выводы | Каноническая политика, журнал версий и хеши протокола | Product / BA | OPEN |
| R-02 | Потеря дублей, ссылок или исходных количеств | Неизменяемая строка и 100% сверка корпуса, независимые тесты входных форматов | Intake Engineer | OPEN |
| R-03 | Доступ Codex ошибочно засчитан как доступ сервера или провайдера | Раздельная capability matrix. Живой вызов из целевой среды | MCP Engineer | OPEN |
| R-04 | Ограничения сайта и поиска тормозят Recovery или вызывают обход | Allowlist, бюджеты вызовов, журнал ошибок. Яндекс только через подтверждённый канал | MCP Engineer | OPEN |
| R-05 | Другой бренд, серия или размер попадают в EXACT | Техническая приёмка в существующем Matcher и независимая регрессия | Backend Engineer | OPEN |
| R-06 | Наличие подменяет доставку, а разрешение на поиск подменяет выбор товара | Независимые поля, scoped approvals и негативные тесты | Backend / Product | OPEN |
| R-07 | Маленький или зависимый эталон искусственно завышает качество | Golden Set на документах изготовителей, UNKNOWN и явные знаменатели | QA Lead | OPEN |
| R-08 | Клиентские данные или секреты попадают в Git либо меняется active runtime без разрешения | Ограниченное хранение, проверка staged diff, тестовый контур и утверждение владельца | Security / Release | OPEN |
