## Общие ворота

Contract Review → Implementation Review → Unit Tests → Integration Tests → Security Review → Evidence Review → Owner Approval, где он применим. Для каждого перехода фиксируются ревизия, результат и ссылка. Статус DONE относится к пройденным воротам конкретной задачи.

Ориентир качества — 95% корректно обработанных строк. Знаменатель включает весь принятый набор. Определение корректной обработки и доля UNKNOWN фиксируются до запуска. Точный SKU, технически допустимое предложение, разрешение на поиск, выбор SKU и поставка измеряются раздельно.
