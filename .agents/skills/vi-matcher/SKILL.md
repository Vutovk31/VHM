---
name: vi-matcher
description: Подбирает товары ВсеИнструменты.ру по заявке из текста, Excel, CSV, PDF или DOCX. Используй для строгого подбора, предложений по открытым позициям и согласованного поиска аналогов с отчётом Excel.
---

1. Прочитай [регламент](references/reglement.md) и [контракт](references/contract.md). Прочитай политику `policy/vi.json`. Работа выполняется из корня проекта.
2. Разбери все товарные строки и сохрани снимок `runs/<request-id>/intake.json`. Сообщи число строк и групп. Используй те же ключи строк при последующем согласовании.
3. Вызови инструменты VI по их текущей схеме и выполни маршрут B из регламента. Записывай попытки и карточки по каждой строке в `evidence.json`. В веб-запросы передавай только товарные признаки. Для прямого поиска по каталогу пользуйся официальным сайтом через доступный браузер. Если канал недоступен, запиши это и продолжи.
4. Выполни `node src/matcher.mjs policy/vi.json runs/<request-id>/intake.json runs/<request-id>/evidence.json runs/<request-id>/result.json`. При ошибке исправь входные записи. Сохрани отчёт и два списка в каталоге заявки. Для Excel используй `src/export.mjs` по контракту. Сообщи долю закрытых групп, число предложений, пробелы и ссылки на результат.
5. Если есть строки для замены, задай вопрос из регламента. После ответа зафиксируй разрешение и продолжи ту же заявку с теми же строками и версией политики. Согласование поиска и утверждение конкретной карточки фиксируй отдельно.

Для программного исполнения в текущей сессии используй [Host bridge](../../../docs/VHM_HOST_BRIDGE.md) и [канонический регламент](../../../docs/policy/VHM_MATCHING_POLICY.md). Сохрани разобранные требования с исходными фрагментами, запусти run-core и обслуживай его запросы доступными инструментами до завершения. Учитывай фактические лимиты коннектора и состояние процесса. Затем проверь checkpoint, экспортируй результат и один раз запроси разрешение на аналоги для разрешаемых строк.
